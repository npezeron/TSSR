# Serveur Exchange

## Composant Principaux

- Serveurs Exchange, Clients (Outlook, OWA), Réseau.
- Consel de Gestion Exchange (EMC)
- Centre d'Administration Exchange (EAC)
- Interface web pour Exchange
- PowerShell pour Exchange (Exchange Management Shell)

# Les protocle

- SMTP: Simple Message Transfer Protocole port.
  - port 25 (ce port n'est pas sécurisé)
  - port 587 (port sécurisé)

- IMAP: permet de consulter les mails
  - Port 143 (non sécurisé)
  - Port 993 (sécurisé)

- POP3: permet de télécharge les mails port 110 
  - Port 110 (non sécurisé)
  - Port 995 (sécurisé)
