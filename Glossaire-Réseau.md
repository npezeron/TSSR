# Glossaire Réseaux

1. **OSI** (Open système interconnection): Permet de décririre comment les donnée circule entre deux résaux

2. **TCP/IP:** Le modèle TCP/IP (Transmission Control Protocol / Internet Protocol) est le modèle d’architecture réseau réellement utilisé sur Internet. Contrairement au modèle OSI, qui est surtout théorique, TCP/IP est issu d’une approche pratique.

3. **BIOS/UEFI:** (Basic Input/Output System) : micrologiciel historique (années 1980) des PC, stocké sur la carte mère. Il teste le matériel au démarrage (POST), puis lance le système d’exploitation depuis le premier secteur du disque (MBR).

(Unified Extensible Firmware Interface) : son successeur moderne, qui remplit le même rôle (initialiser le matériel et démarrer l’OS) mais avec davantage de fonctionnalités.

4. **ISO**: Fichier qui contient l'image d'un OS, se qui permet de l'installer 

5. **WDS**: Service qui permet le déploiement d'une image via un windows serveur sur un poste qui de en PXE

6. **BRIDGE/NAT/HOST-ONLY:** Ces trois modes déterminent comment une VM (VirtualBox, VMware, etc.) se connecte au réseau.

7. **PXE(preboot execution environnement)**: Permet à postge qui n'a pas d'OS de se connecter à un serveur pour qu'il puisse recevoir une image depuis le dit serveur.

8. **DHCP:** Permet d'attribuer une  configuration IP depuis un pool d'ip et un bail à un poste pour qu'il puisse se connecter à un serveur.

9. **MBR/GPT(Master boot record/ GUID Partion table):** 2 type de table  de partion 

10. **Partition:** La Partition est un segment définie ou automatique d'un espace de stockage

11. **NTFS:** Système de fichier qui est utilisé le plus souvent. Chaque système de fichier permet de transférer des fichier plus ou moins volumineux ex: le FAT 32 ne peux transférer des fichier que de 2Go maximum

12. **SHAT256(Signature):** Permet de d'attester l'intégrité d'un programme/fichier 

13. **VMWare:** Logiciel qui permet de faire de l'hypervision de type 1 ou 2 
  - VMware workstation: type 2
  - VMware exs: type 1

14. **Windows Serveur** OS de Windows qui est dédier à la créatiion et déploiment de services

15. **DNS (Domaine name service:)**: 
Permet de résoudre le nom de domaine en adresse IP

16. **IP/MAC:** L'IP est un identifiant sur un réseaux qui est sur 4 octets en décimale

MAC: Identifiant matériel en Hexadecimale sur 6 Octets

17. **IEEE 802.3/11:** Norme ethernet et WIFI
